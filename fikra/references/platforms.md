# Platform Guidance

Use this reference when creating or reviewing content for the six supported platforms: Instagram, TikTok, LinkedIn, X, Facebook and YouTube.

Do not duplicate one text across platforms. Preserve the core message while changing the format, pacing, depth, opening, and call to action.

## Instagram

Use Instagram for visual storytelling, saves, shares, and community interaction.

### Suitable formats

- Carousel
- Reel
- Single-image post
- Story adaptation

### Instagram post

- Begin with a clear first line that creates interest without misleading.
- Keep paragraphs short and easy to scan.
- Build one main idea rather than several competing messages.
- Use a call to action suited to the objective, such as saving, sharing, commenting, visiting, or requesting information.
- Use a limited number of relevant hashtags only when they add discovery value.

### Carousel

Provide:

1. Cover text
2. Slide-by-slide structure
3. One clear point per slide
4. A logical progression
5. A final takeaway or call to action

Keep cover text concise and visually readable.

### Reel

Provide:

- Hook for the first three seconds
- Spoken script
- Scene or shot sequence
- On-screen text
- Suggested visual rhythm
- Ending and call to action

Do not overload the video with unnecessary transitions or text.

## TikTok

Use TikTok for fast, human, conversational, and visually active content.

### TikTok script

- Start directly with the problem, question, result, or surprising observation.
- Avoid long introductions and formal greetings.
- Use natural spoken language.
- Maintain momentum through clear beats or scene changes.
- Demonstrate, explain, compare, or tell a short story.
- End with a natural invitation to respond, follow, try, or continue to another part.

Provide:

- Target duration
- Opening hook
- Spoken script
- Scene breakdown
- On-screen text
- Suggested shots
- Closing action

Do not invent a trend, sound, challenge, or platform feature. If live trend information is unavailable, label any trend-based idea as requiring current verification.

## LinkedIn

Use LinkedIn for professional insight, expertise, lessons, case-based content, and constructive discussion.

### LinkedIn post

- Open with a meaningful professional observation, tension, lesson, or question.
- Establish why the subject matters.
- Develop one coherent argument or experience.
- Use examples only when supplied or clearly presented as hypothetical.
- Keep the tone credible and human rather than promotional or overly formal.
- End with a useful takeaway or a focused discussion question.

For personal-brand stories:

- Preserve the user's real experience.
- Do not invent achievements, employers, results, or personal details.
- Connect the experience to a lesson useful to the audience.

For business content:

- Explain value before promoting the product or service.
- Avoid unsupported claims and exaggerated leadership language.

## X

Use X for concise insight, timely discussion, clear opinions, and structured threads.

### Single post

- Express one main idea.
- Remove unnecessary introductions.
- Make the wording precise and easy to understand.
- Use a question only when it invites meaningful discussion.

### Thread

Provide:

1. A strong opening post that states the subject and value.
2. A logical sequence in which each post adds new information.
3. Short, focused sections.
4. A final summary, takeaway, or question.

Do not divide a long paragraph arbitrarily. Each post should have an individual function within the thread.

## Facebook

Choose page text/image posts, single images, multi-image posts or a carousel only when the actual tool and format support it, Facebook Reels, or Stories according to the campaign objective. Content planning is supported; no format is guaranteed for every account or tool. Check current actual format, account and tool capabilities before production, publication, scheduling or analytics using [execution-and-connections.md](execution-and-connections.md).

For page posts, provide the final text, image brief/order where relevant, accompanying caption and a natural invitation to comment, share, visit or ask a question. For video, include its description and accompanying post text. For Stories, provide the frame sequence, concise on-screen copy and intended interaction, without promising unsupported interactive features.

For a Facebook Reel, specify target duration, an honest opening, spoken script, on-screen text, shots, pacing, ending and accompanying caption. Adapt the opening, duration and rhythm for the Facebook audience and goal; review rather than copying an Instagram Reel or TikTok script literally. Actual production uses the existing tool-choice and approval gate.

When repurposing Instagram content, retain the message but reconsider context, depth, image sequence and call to action for the Facebook page's audience. Explain the useful adaptation. Provide a proposed posting schedule/timezone and an objective-linked measurement plan; timing is a hypothesis, and named metrics are candidates until the connected tool confirms availability. Publishing, scheduling and analytics require verified documented access, suitable permissions and user approval.

## YouTube

Choose only the deliverables that fit the goal and audience. Keep these types distinct in the plan, preview and execution status:

| Deliverable | What it means |
| --- | --- |
| YouTube Short | A short-video concept/script, or a produced short video when an actual file is verified; label which exists. |
| Long YouTube video | A longer structured video project; script completion is separate from production completion. |
| Community Post | A separate channel post, only when appropriate and supported by the actual account and tool; do not assume a video-upload tool can publish it. |
| Thumbnail | A separate cover image; a brief/title is not an actual thumbnail file. |
| Video script | Written narration, scenes and on-screen directions; not an uploadable video. |
| Actual uploadable video | A verified accessible video file with required properties, sound and subtitles where requested; readiness does not authorize upload. |

### Shorts

Specify target duration, an honest opening, spoken script, on-screen text, shots, pacing, ending and accompanying description. Adapt for the YouTube audience and purpose, rather than copying TikTok or Instagram Reels verbatim. If actual production is requested, use the existing tool-choice and approval gate. Verify current format constraints from official documentation and the available tool at execution time rather than assuming fixed limits.

### Long video

Ask for target duration, or propose a suitable range and request confirmation when it affects production scope, cost or structure. For script-only work, an explicitly labeled estimated duration can guide the draft. Build:

1. A strong, truthful opening that states the value or question without misleading promises.
2. Clear sections and scene progression, with useful transitions and continuous viewer value rather than filler.
3. Spoken narration/voiceover text, on-screen text and supporting scene/visual directions.
4. A conclusion that fulfills the opening and naturally invites subscription, a comment or another useful action.

Provide titles, descriptions and subject-relevant keywords; never label keywords as trending without evidence. Add a thumbnail brief and concise cover text aligned with the video's actual content. Translation and actual subtitle files depend on available tools; distinguish translated text, subtitle files and subtitles visibly rendered into video, obtaining media-tool permission when required.

Before a final video exists, supply section names and estimated pacing only, explicitly labeled as planning estimates. Do not create final timestamped chapters until the actual final video and measured timings exist. Derive chapter boundaries from that final cut, validate against its real duration and revise after editing.

For actual production, check required video, voice/audio, editing, thumbnail and subtitle capabilities, then obtain tool approvals. Inspect the real exported video, including playability, duration, dimensions, sound/image synchronization and subtitle timing/readability when production tools allow. Record unverified or failed checks; never call a script, prompt or job ID a completed video or ready for upload.

### Community, repurposing and measurement

Create Community Posts only when appropriate and supported by the intended channel and tool; otherwise state the limitation and offer a clearly labeled text draft if useful. A thumbnail, Community Post and video upload are separate assets/actions.

To turn a long video into Shorts or excerpts, use actual supplied/produced source footage and meaningful self-contained segments. Adapt framing, opening, captions and ending for each excerpt. Without real source media, offer a repurposing plan only, not finished clips. Editing remains behind tool approval.

Propose a schedule and measurement window tied to the goal. Uploads, scheduling and analytics require verified documented connection, suitable permissions and explicit user approval. Use only returned metrics, not assumed dashboard fields; view count alone does not establish campaign success.

## Cross-Platform Campaign Design

Assign a distinct role to each selected platform.

Example:

- TikTok introduces the problem through a conversational short video.
- Facebook uses a page post or Reel to invite audience discussion.
- YouTube uses a Short for one takeaway or a long video for a structured explanation.
- Instagram carousel explains the practical steps.
- LinkedIn provides professional context or a lesson.
- X opens a focused discussion or summarizes key observations.

Select the formats that serve the objective, audience and available materials, and explain why. This example is not a requirement to use every platform or format. Change the content architecture rather than only changing its length.

## Platform Selection

When the user has not selected platforms:

- Recommend only the platforms that serve the audience, objective, and available production resources.
- Explain the recommendation briefly.
- Do not require the user to publish on every supported platform.

## Timing, Trends, and Hashtags

Publishing timing, current trends, and hashtag performance can change.

- Do not present a publishing time as universally optimal.
- Do not invent current trend data.
- Do not promise reach based on hashtags.
- Label timing and trend suggestions as hypotheses that should be tested or verified using current account data.
